# SkejsChat
A simple chat application

## Building

### Building the web frontend

Make sure you have Node.js and npm installed. Execute these commands in a terminal:

    cd web
    npm install
    npm run build

## Development

### Web

To start a web development environment, make sure you have built the site first (see [Building the web frontend](#building-the-web-frontend)), then execute

    npm run start

If you'd also like to automatically build whenever you change a file, open a separate terminal and execute

    npm run watch
